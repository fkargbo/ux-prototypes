## 🎯 For Team Leads: How to Roll This Out

### 1. Setup Session (1 hour)

Schedule a hands-on session:

**Agenda:**
- Show the prototype launcher (5 min)
- Walk through copying template (5 min)
- Edit config file together (10 min)
- Add components live (20 min)
- Q&A (20 min)

**Everyone leaves with a working prototype!**

### 2. Pairing Strategy

Pair each designer with a developer for their first prototype:

- Designer explains what they want to build
- Developer helps with initial setup
- Designer builds the UI
- Developer available for questions

**After the first one, designers are independent!**

### 3. Component Workshop (Optional)

Show designers the most useful components:

- **Layouts:** PageSection, Grid, Flex
- **Content:** Card, List, Table
- **Actions:** Button, Toolbar
- **Feedback:** Alert, Modal, Empty State
- **Forms:** TextInput, Select, Checkbox

Provide a "cheat sheet" with copy-paste examples.

### 4. Office Hours

Set up weekly office hours:
- Designers can drop in with questions
- Share tips and tricks
- Show cool examples
- Troubleshoot issues

### 5. Success Stories

When designers complete prototypes:
- Share in team channel
- Document findings
- Celebrate quick iterations

**Show the value!**

## 🎯 Key Messages for Designers

### 1. "You Won't Break Anything"

Your prototype is **100% isolated**. Experiment freely!

### 2. "No Code Required"

Copy-paste components like LEGO blocks. Change text and properties.

### 3. "Iterate Fast"

Make a change, save, see it instantly. Test with users same day.

### 4. "Real Components"

Not sketches or mockups—actual PatternFly components users will use.

### 5. "Independence"

Work at your own pace. No waiting for developers.

### 6. "Collaboration"

Share prototypes easily. Archive when done. Learn from others.
