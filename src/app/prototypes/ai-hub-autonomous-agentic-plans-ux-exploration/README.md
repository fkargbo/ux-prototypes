# AI Hub - Autonomous agentic plans (MVP)

## Purpose

Isolated MVP prototype for autonomous agentic remediation plans in AI Hub. The **AI Hub page** is a full copy of the Observability Agentic Troubleshooting prototype’s AI Hub experience (Fleet overview, Plans & approvals, Audit & logs).

## Setup

1. Select **AI Hub - Autonomous agentic plans (MVP)** from the prototype launcher.
2. Open **AI Hub** in the sidebar.
3. Use the banner version picker (v1 / v2 / v3) and appearance settings as in the source prototype.
4. Use the Lightspeed toggle (bottom-right) for the global agent chat.

## Notes

- This prototype is **fully isolated** from `observability-agentic-troubleshooting-ai` — no shared imports between the two prototype directories.
- Changes here do not affect the Observability prototype and vice versa.
