## Overview

This prototype explores AAQ (Advanced Allocation & Quotas) for OpenShift Virtualization, focusing on how administrators create and manage resource quotas for VM workloads.

## Research Goals

- Test quota creation workflow
- Validate resource limit settings
- Assess understanding of quota scopes
- Evaluate quota management patterns
